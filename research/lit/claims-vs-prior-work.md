# Claims vs. prior work

**Status: agreed with the owner, 2026-10-25 ([MAR-28](https://linear.app/marc-prinzing/issue/MAR-28), [MAR-84](https://linear.app/marc-prinzing/issue/MAR-84)).** This file backs up [`positioning.md`](positioning.md). Citation keys refer to [`references.bib`](references.bib). Per-source summaries, the sources used to verify each entry, and observations O1–O4 are in [`notes.md`](notes.md).

The tables describe what each work *does*. They make no performance comparison (publication rule, AGENTS.md).
