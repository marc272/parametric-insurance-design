# Data sources

The data this project uses, and the terms each comes with. Data licences are separate from code licences (ADR 0001).

## Rules

- **No data is committed**, except small test fixtures. Downloads go through scripts that check checksums (`AGENTS.md`, `docs/SPEC.md` §4.3).
- Every EventSet records its source and licence in `metadata.json` (`docs/SPEC.md` §5).
- Data derived from a source keeps that source's terms, unless the source says otherwise.
- **Never guess a licence.** An entry is "verified" only when its licence was read from the primary source; record the date and the URL you read it from. Until then it stays "to verify", with the issue that will verify it.

### IRIS licence check (MAR-9)

Checked on 2026-10-25 for MAR-9, before committing the thesis parity fixture.

- **Primary source.** Sparks and Toumi's IRIS dataset is hosted on Springer Nature figshare as the collection "IRIS: The Imperial College Storm Model", <https://doi.org/10.6084/m9.figshare.c.6724251.v1> (version 1, posted 2024-04-23). It holds two items, each with its own licence field:
  - "Main dataset" (`IRIS_event_set.zip`), <https://doi.org/10.6084/m9.figshare.24894186.v1>: licence **CC0** (<https://creativecommons.org/publicdomain/zero/1.0/>).
  - "File descriptor" (`IRIS_event_set_README.txt`), <https://doi.org/10.6084/m9.figshare.24894189.v1>: licence **CC0**.
- **How it was read.** The figshare HTML pages refused automated access (HTTP 403), so the licence fields were read from figshare's public API records of the same items: <https://api.figshare.com/v2/articles/24894186> and <https://api.figshare.com/v2/articles/24894189>. The collection record (<https://api.figshare.com/v2/collections/6724251>) carries no licence of its own.
- **The article.** The data descriptor (Sparks, N. and Toumi, R., *Scientific Data* 11, 2024, <https://doi.org/10.1038/s41597-024-03250-y>; read at <https://pmc.ncbi.nlm.nih.gov/articles/PMC11043368/>) is under CC BY 4.0. Its Data Records section points to the figshare collection above. That licence covers the article, not the dataset.
- **Result (MAR-9; superseded by the [MAR-94 decision](#decision-treated-as-cc-by-40-mar-94)).** CC0 places no restriction on redistributing the data or works derived from it, so the derived per-asset losses may be committed and published. The parity fixture is committed under `parity/tests/data/thesis_eventset/`; its `metadata.json` first recorded the licence as `CC0-1.0`, following the rule above that derived data keeps the source's terms. Since the MAR-94 decision it records `CC-BY-4.0`.
- **Attribution.** Under the CC BY 4.0 treatment (MAR-94) attribution is required, and scientific practice asks for it anyway: cite the data descriptor and the figshare collection wherever IRIS-derived data or results appear.
- **Scope.** This covers the IRIS event set only. The raw IRIS tracks are still not committed (size; they are fetched by the CLIMADA adapter, MAR-19). The derived losses were computed with CLIMADA, whose code is GPL-3.0. The GPL covers CLIMADA's code, not its numeric output: CLIMADA's own documentation states no terms for results, and the GNU GPL FAQ says output inherits the status of its input (<https://www.gnu.org/licenses/gpl-faq.html#GPLOutput>, read 2026-10-25). Confirmed by the owner on 2026-10-25 (MAR-79, ADR 0001 amendment 1). The asset portfolio is the owner's own.

- **Observation.** The records genuinely differ. Both items, the only files in the collection and the ones the script downloads, are CC0 in figshare and in DataCite. The collection's DataCite record is CC BY 4.0. figshare's own collection record has no licence field. No record says which one governs, and this check does not choose.

At the time of this check the parity fixture's `metadata.json` recorded `CC0-1.0` (MAR-9).
- **Not reachable.** The figshare HTML pages for the collection did not serve automated requests (HTTP 202 with an empty body), so the human-readable pages were not read.
- **Open at the time.** Which record governs was for the owner to decide; he did under MAR-94 (below).

#### Decision: treated as CC BY 4.0 (MAR-94)

Decided by the owner, Marc Prinzing, on 2026-10-27 (MAR-94; ADR 0001, amendment 1).

- **Both records listed; treated as CC BY 4.0 by owner decision (MAR-94).** The records above stay as they are. IRIS-derived data is treated as CC BY 4.0, the stricter of the two.
- **What records it.** The parity fixture's `metadata.json` records `CC-BY-4.0`. The CLIMADA adapter writes `CC-BY-4.0` into every EventSet it builds from IRIS by default (`licence_applied` in `iris_manifest.json`, which keeps the two recorded licences under `licence` and the decision under `licence_resolution`). The Florida EventSets (MAR-114) are CC-BY-4.0 already, through LitPop as well.
- **What it asks of outputs.** Every output that uses IRIS-derived data gives credit (cite the data descriptor and the figshare collection, as the "Attribution" point above asks), links to the licence (<https://creativecommons.org/licenses/by/4.0/>), and indicates changes (for example: per-asset losses computed with CLIMADA from the IRIS tracks).
- **The thesis result tables** in `parity/golden/`, the simulation-sweep tables included, are **CC0-1.0** by the same decision (`parity/golden/LICENSE`).

### LitPop and Overture licence check (MAR-30)

Checked on 2026-10-25 for MAR-30, while preparing the D2 note (`research/notes/d2-paper-portfolio.md`). No data was downloaded; only documentation pages and metadata records were read.

- **LitPop, CLIMADA data API.** The dataset records that `climada.util.api_client.Client` downloads (<https://climada.ethz.ch/data-api/v2/dataset/?data_type=litpop&status=active>) number 684 active records, and every one has `"license": "Attribution 4.0 International (CC-BY-4.0)"`. Each record also lists its files with an MD5 checksum (for example `LitPop_150arcsec_USA` v3, uuid `678e9551-32ca-40f3-9881-9bd38412c1cd`, `md5:9f019394e1736e67c6fd5572875a2fa1`). The data-type record (<https://climada.ethz.ch/data-api/v2/data_type/>) asks users to cite Eberenz et al. (2020) and the ETH archive.
- **LitPop, ETH archive.** The DataCite record registered by ETH Zurich for doi:10.3929/ethz-b-000331316 (<https://api.datacite.org/dois/10.3929/ethz-b-000331316>) gives "Creative Commons Attribution 4.0 International" (SPDX `cc-by-4.0`). The ETH landing page itself was not opened.
- **LitPop inputs.** GPW v4.11 population count is "openly shared, without restriction" (NASA Earthdata catalogue, <https://www.earthdata.nasa.gov/data/catalog/sedac-ciesin-sedac-gpwv4-popcount-r11-4.11>). The terms of NASA Black Marble and of the World Bank wealth accounts were not checked. The CLIMADA LitPop tutorial states no licence. Regenerating LitPop locally needs GPW TIFFs behind a free NASA login (the tutorial says so), which only the owner may use.
- **LitPop, result.** CC BY 4.0 allows publishing derived EventSets, figures and tables with attribution. An EventSet built from LitPop records `CC-BY-4.0` in its `metadata.json`.
- **Overture Places.** The places guide states that Places is published "under the CDLA Permissive 2.0 and Apache 2.0 licenses, depending on the source" and contains no OpenStreetMap data, so no ODbL share-alike. The attribution page (last updated 2026-05-15) lists the sources: Meta, Microsoft, PinMeTo, Krick, RenderSEO, DAC, BrightQuery, Birdeye, Uberall and OpenTravel Alliance under CDLA-Permissive-2.0; Foursquare under Apache-2.0, with a copyright line and a NOTICE file (<https://opensource.foursquare.com/places-notice-txt/>); AllThePlaces under CC0 1.0. Suggested citation: "Overture Maps Foundation, overturemaps.org" with the access date.
- **CDLA-Permissive-2.0** (<https://cdla.dev/permissive-2-0/>): sharing the data requires the licence text to go with it (§2.1); the licence places no restriction on Results, meaning outcomes of computational analysis (§3.1, §5.4).
- **Overture's other themes** (Buildings, Divisions, Base, Transportation) are ODbL 1.0, "© OpenStreetMap contributors". Under ODbL (<https://opendatacommons.org/licenses/odbl/1-0/>), a publicly used derivative database stays ODbL (§4.4) and a publicly used produced work needs a notice (§4.3). Values or boundaries taken from these themes would carry that.
- **Not checked:** per-file checksums for Overture releases (none seen on the pages read); boundary files for LitPop aggregation (TIGER/Line, geoBoundaries), which need their own rows before use.

### TIGER/Line licence check (MAR-113)

Checked on 2026-10-27 for MAR-113, before the county boundaries were used to build the D2 locations table.

- **Choice.** The U.S. Census Bureau's TIGER/Line counties rather than geoBoundaries ADM2: TIGER/Line is the government's own county file (geoBoundaries' licence and upstream source were not checked), its county polygons include the coastal water areas, so coastal LitPop cells fall inside a county rather than in no unit, and the national file also holds the neighbouring states' counties, so cells across the Florida line are counted as "in another county", not as unassigned. TIGER/Line has no per-state county file, so the national file (84 MB) is downloaded.
- **Primary source.** The ISO 19115 metadata record that the Census Bureau publishes with the file (`tl_2025_us_county.shp.iso.xml`, inside the downloaded zip and at <https://meta.geo.census.gov/data/existing/decennial/GEO/GPMB/TIGERline/Current_19115/tl_2025_us_county.shp.iso.xml>, metadata dated 2025-09-18). Its constraints read: "Access constraints: None"; and, under use constraints, that the TIGER/Line Shapefile products "are not copyrighted", that they "are free to use in a product or publication, however acknowledgement must be given to the U.S. Census Bureau as the source", that TIGER/Line and Census TIGER are registered trademarks, and that the boundaries are for statistical data collection and tabulation and are not legal land descriptions.
- **Not reached.** The census.gov HTML pages (TIGER/Line product page, data-use pages) timed out for automated requests; the download host www2.census.gov and the metadata host served normally. The TIGER/Line technical documentation PDF was downloaded but not parsed (no PDF tool in the environment).
- **Result.** The derived county values and centroids may be published. Every output that uses them acknowledges "U.S. Census Bureau, 2025 TIGER/Line Shapefiles" next to the LitPop CC BY 4.0 attribution. The combined locations table is recorded as `CC-BY-4.0` (the LitPop terms; the boundaries add only the acknowledgement).
- **Datum.** The polygons are in NAD83 (EPSG:4269) and are reprojected to WGS 84 (EPSG:4326), LitPop's datum, before the cells are assigned. The two datums differ by the order of a metre, far below the 150-arcsec (about 4.6 km) cell size.

### STORM licence check (MAR-32)

Checked on 2026-10-27 for MAR-32, before any STORM data was used. D7 (MAR-62, SPEC §11) chose STORM present climate, version 4, North Atlantic.

- **Primary source.** The repository's DataCite record of the dataset DOI, <https://api.datacite.org/dois/10.4121/12706085>, registered by 4TU.ResearchData: title "STORM IBTrACS present climate synthetic tropical cyclone tracks", version 4, publication year 2022, rights "Creative Commons Zero v1.0 Universal" (SPDX `cc0-1.0`, <https://creativecommons.org/publicdomain/zero/1.0/legalcode>), related to the data descriptor doi:10.1038/s41597-020-0381-2.
- **Landing page.** `data.4tu.nl` refused or timed out every connection on 2026-10-25 (MAR-62) and on 2026-10-27 (MAR-32, from both the shell and the web fetcher), while other hosts answered. The Internet Archive's copy of the landing page <https://data.4tu.nl/articles/_/12706085> of 2026-03-30 carries schema.org metadata with `"license": "https://creativecommons.org/publicdomain/zero/1.0/"`, `"version": 4` and the citation "Bloemendaal, Nadia; Haigh, I.D. (Ivan); de Moel, H. (Hans); Muis, S; Haarsma, R.J. (Reindert) et. al. (2022) … Version 4. 4TU.ResearchData". This archived copy agrees with the DataCite record but is not the live page. Re-read the live page when the download script is written.
- **File layout (for the download script).** From archived copies of two of the dataset's files (the README and the start of a zip): each file holds 1,000 years of one basin, named `STORM_DATA_IBTRACS_<basin>_1000_YEARS_<k>.txt`, `k` = 0 … 9, inside a zip folder `VERSIE4/`. The files are comma-separated with 13 columns and no header: year (restarts at 0 in every file), month, TC number, 3-hourly time step, basin ID (1 = NA), latitude, longitude (0–360° E), minimum pressure (hPa), maximum wind (m/s, 10-minute mean), radius of maximum winds (km), category, landfall flag, distance to land (km). No checksum was taken from these copies: the manifest must pin the files served by 4TU itself.
- **Result.** CC0 1.0: STORM-derived data may be published with no conditions. Outputs cite the data descriptor (Bloemendaal et al. 2020, *Sci. Data* 7, 40) and the dataset DOI anyway. The Florida STORM EventSets combine STORM with LitPop (CC BY 4.0), so they record `CC-BY-4.0`, the stricter of the two (`configs/florida_counties_storm*.yaml`).

## How to add or update a source

1. Add a row before the data is first downloaded or used.
2. Read the licence on the primary source (the provider's own page, not a mirror or a paper citing it). Write it down, with the URL and the date.
3. Record anything that limits use: non-commercial clauses, attribution text, redistribution, and whether derived results may be published.
4. If the terms are unclear or restrictive, escalate to the orchestrator before using the data.
