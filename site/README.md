# site/

The project website will live here: interactive explorers of the payout design, and the posts. It isn't built yet, so this folder holds only this README.

- The stack is decided: Quarto with Observable JS, deployed to GitHub Pages ([ADR 0003](../docs/adr/0003-website-stack.md)).
- The site will read bundles exported from the result store and never run an optimisation itself ([`docs/SPEC.md`](../docs/SPEC.md) §4).
- Everything published here follows the publication rule in [`AGENTS.md`](../AGENTS.md).

The repository's [README](../README.md) has the project's status.
