# showcase/crc/

The record of how the program's Climate Risk Commons (CRC) work was planned. This folder holds this README, the licence, the [collaboration scan](COLLABORATION-SCAN.md) of CRC's public repositories (options and questions) and a [meeting brief](MEETING-BRIEF.md).

Since 2026-11-05 the CRC work is a parametric insurance module in the CRC SDK, `crc_sdk.parametric`, with a showcase notebook in crc-docs. Both are built in forks of RiskThinking's repositories and contributed upstream, so this folder holds no notebook. The module plan is in [`docs/SPEC.md`](../../docs/SPEC.md) §8, and the module design is ADR 0005 (MAR-244, in preparation). The scan and the brief stay here as the record.

- No CRC or VELO data is committed. Data terms are recorded in [`docs/data-sources.md`](../../docs/data-sources.md).
- Licence: this folder's files are BSD-3-Clause ([`LICENSE`](LICENSE); [ADR 0001](../../docs/adr/0001-name-and-licence.md), amendment 1).

The repository's [README](../../README.md) has the project's status.
